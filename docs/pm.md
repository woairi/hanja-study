# PM 노트

## 한 줄 목표
- 아이가 **모바일에서 매일 5~10분** 한자(어문회 급수) 학습을 **지속**하게 만드는 무료 서비스.

## MVP 범위(확정)
- 급수: 8급, 7급, 7급Ⅱ, 6급, 6급Ⅱ, 5급, 4급, 4급Ⅱ
- 사용자: 아이만 사용(로그인 없음)
- 수익: 무료
- 학습: 오늘 목표(5/10/15자 선택) → 학습 카드 → 퀴즈(함정 20%) → 진도
- 복습: SRS 라이트(맞힘 +3일/+7일, 틀림 +1일, 마스터링 기준)

## 성공 기준(초기)
- 1회 세션 완료까지 이탈 없이 진행(학습 n자 + 퀴즈 완료)
- 스트릭이 최소 3일 이상 유지되는 사용자 관찰

## 리스크/가드레일
- 데이터 출처/급수 구성 차이(출처 1곳 고정 필요)
- 쓰기/획순은 MVP에서 제외(모바일 입력 부담으로 이탈 위험)
