# FE 노트

## 화면 구조(모바일)
- `/` 급수 선택 + 오늘 목표(5/10/15자) + 스트릭
- `/study` 학습 카드(한자 크게, 뜻/음 숨김→보기)
- `/quiz` 4지선다(뜻/음) + 함정문제(한자 구분)
- `/progress` 급수별 진행률 + 복습 대기 + 취약 TOP

## UI 원칙
- 초등 사용자: 글자 크게, 버튼 크게(최소 44px)
- 한자 카드: **한자(최상단, 매우 크게)** → 뜻/음(한 번에)
- 퀴즈: 옵션 버튼은 전면 클릭(탭 실수 방지)
- 결과: 점수만 간단히, 다음 행동(홈/진도) 2버튼

## 다음 개선(우선순위)
- 퀴즈 정답/오답 피드백(짧게): 다음 버튼 누르기 전에 0.5~1초 하이라이트
- 학습 카드에 예시 단어 표시(선택) + 너무 긴 텍스트 방지
- 다크모드/고대비(시력/가독성)
