# Sub-agent 작업 기록 (요약)

이 문서는 OpenClaw의 역할별 서브에이전트(pm/fe/be/qe/uxreview)가 수행한 작업/결정 사항을 한 곳에 모은 요약본이다.

> NOTE: 실제 구현은 `web/` 및 `data/`에 반영되어 있으며, 본 문서는 추적/인수인계를 위한 메모다.

## 공통 컨텍스트

- 목표: 초등학생 대상 한자 학습 웹서비스(무료, 모바일 우선)
- 커리큘럼: 어문회 급수 기준
- 범위: 8급~4급 + 7급Ⅱ/6급Ⅱ/4급Ⅱ 포함
- 계정/로그인: 없음(기기 로컬 저장)
- 퀴즈: 뜻/음 + 함정문제(비슷한 한자 구분) 20%

## 문서 목록

- `docs/pm.md` : 제품 정의/MVP 범위/성공 기준
- `docs/fe.md` : UI/화면 설계 및 컴포넌트 관점
- `docs/be.md` : 데이터 구조/로직(SRS)/라우팅 및 상태 저장
- `docs/qe.md` : 테스트 포인트/엣지케이스/수동 QA 체크리스트
- `docs/uxreview.md` : UX 개선 제안(초등 사용자 기준)
