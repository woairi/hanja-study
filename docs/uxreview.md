# UX Review 노트

## 타겟(초등)
- 글자 크게, 동작 단순, 한 번에 1가지 행동만 요구
- 실패(오답) 시 스트레스 최소화: 짧은 피드백 + 바로 다음

## 현재 MVP의 좋은 점
- 급수 선택이 명확
- 오늘 목표를 5/10/15로 고를 수 있어 부담 조절 가능
- 함정문제(구분)로 "진짜 아는지"를 확인 가능

## 개선 제안(우선순위)
1. 퀴즈 피드백: 정답/오답을 0.7초 표시하고 다음으로(학습효과↑)
2. 진도에서 "복습하기" CTA 버튼 추가(due가 있으면 바로 시작)
3. 학습 카드에서 뜻/음 보여준 상태에서 스와이프(next) 지원(모바일 친화)
4. 스트릭 보상: 3일/7일/14일 뱃지(과도한 과금 UX는 지양)

## 함정문제 품질
- 랜덤 distractor만으로는 납득감이 낮을 수 있음
- `confusables`를 보강하면 학습효과/재미가 크게 올라감
